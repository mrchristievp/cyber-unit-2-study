# Cyber Study Lab — Unit 2

An untimed cybersecurity study website with 60 original quiz questions and five written-response workshops.

## Features

- Mixed ten-question reviews covering all six topics.
- Topic practice with new questions prioritized.
- Shuffled answer choices, misconception-based distractors, and explanatory feedback.
- FRQ response fields, self-check rubrics, sample responses, and text downloads.
- Progress and drafts stored in the visitor’s browser; no student accounts or teacher submissions.

## Topics

Social engineering; adversaries and attack activities; risk assessment; risk responses; controls and layered defenses; CIA principles and evidence.

## Run locally

Serve this directory with any static web server, for example `python -m http.server 8000`, then open `http://localhost:8000`.

## GitHub Pages

Publish the `main` branch from the repository root. All asset paths are relative, so the website works under a repository path.

## Content

These are study scenarios for applying concepts, rather than copies of the classroom test. All 60 items were reviewed for plausible distractors and comparable option length. FRQ self-checks are not automatic grades.
